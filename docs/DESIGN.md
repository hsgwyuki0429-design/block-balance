# グリッド連鎖版（2026-09-21 改訂）

以前の物理パズルから、1マス単位の支持・落下・消去に変更。

## 採用した仕様

固定1マス土台から始める。ブロックは正方形セルの集合で、形は一体として扱う。水平位置は整数マス。回転は投入前に90度単位で可能。下に1セルでも別ブロックがあれば形全体が停止し、重心・傾き・摩擦は扱わない。支持が土台までつながらない形は1段ずつ同時落下する。

同色の異なる形が上下左右で触れたら両方の形全体を消去。落下途中の接触も対象。斜めは対象外、形内部の同色セル同士では消えない。白い土台は常に残る。支えを失った形は再落下し、次の消去が起きれば同じ投入内の連鎖として加算する。

下に落ちたらゲームオーバー。終了後は投入不可でリセット可能。画面の土台位置は固定し、構造の拡大に合わせてズームする。着地予測は表示しない。

## 試遊用の具体値

- 3候補、使った枠のみ補充、10形状、4色。
- 1段0.18秒の等速落下。物理エンジンはゲームに使用しない。
- 2形以上の同色接触で消去。各接触グループの同時消去は1連鎖分。
- 消去後は0.36秒の発光表示を挟み再落下。
- 得点は消去セル数×100×2^(連鎖数−1)、倍率は2^20で上限。
- 連鎖は1回の投入内で継続。次の投入で現在の連鎖数をリセット、最高記録は保持。
- ブロックの一番上のセルが土台より5マス下に到達すると終了。
- 落下・消去解決中は追加投入せず、連鎖終了を待つ。

次の試遊では、消去しやすさ、倍率、落下速度、形の出現率、画面内の操作幅を調整する。
