# ブロックバランス：企画と試作の境界

## ゲームの核

1×1マスの小さな土台から、正方形のマスを組み合わせた様々な形を重力で落とし、左右と上方向へ構造物を育てる物理パズル。最終的には高得点を目指すゲームを想定するが、まず「積むだけでも面白いか」を確認する。

落下中から物理演算を有効にする。接触すると引っ掛かる、傾く、滑る、崩れる、別の場所へ落ちる。斜めになっても続行でき、マス目への吸着はしない。着地予測・着地ゴーストは表示しない。落下前に見えるブロックは、落下開始位置の表示。

形はテトリミノに限定しない。コの字、追加マス付きL、長い橋、左右非対称、複雑な凹凸など、形そのものを面白さにする。「この形が来たら使いたい」と思える形を見つける。

盤面には左右の壁を設けず、構造物に合わせたズームと、下へ落ちるブロックのフェードを使う。大量のブロックに対する負荷対策は今後の課題。

## この試作の仮設定

- 土台は動かない1×1の固定物体。床や側壁はない。
- 10種類の形、4色。色は識別表示のみ。
- 3択、回転不可が初期値。使用した枠だけ即座にランダム補充する。
- 候補の向きもランダム。1択と落下前90度回転を設定で比較できる。
- 落下後は位置や回転を操作できない。物理シミュレーションは継続する。
- 連打を避けるため落下操作に0.45秒の間隔を設ける。
- 次の落下開始位置は現在の全ブロックの上端より上。揺れの収束は待たなくてもよい。
- 下へ十分落ちたブロックは除去・ロスト数に加算。ゲームは終わらない。
- 高さ・幅・投入数・ロスト数を表示。高さと幅は落下中を含む瞬間の外形で、得点ではない。
- 摩擦・重力は試遊中に調整可能。リセットは試遊設定を維持する。

## 未確定のルール

色の案Aは同色接触による接着。同色部分を一つの大きな個体として扱い、土台の横方向拡張や安定した巨大構造物につなげる。案Bは同色接触による消去（2個接触した瞬間の消去など）。支えが消えると上のブロックが落ち、別の接触を起こす物理連鎖を狙う。案Cは接着後に条件を満たすと消える方式。いずれもまだ採用しない。

スコアは高さによる倍率、コンボ、構造物の規模、危険なバランスへのボーナスなどを検討。高さ専用ミニモードも候補。画面外への落下だけで即ゲームオーバーにするかは再検討し、大きな構造物の小片が落ちただけで終了させるかも試遊で判断する。

回転可否、候補数と補充方式、色の接着／消去／両立、消去必要数、コンボ、終了条件、スコア、形の種類／サイズ／出現率、物理強度、崩れやすさ、操作での救済範囲は未確定。

## 試遊で確認したいこと

1. ただ積むだけで続けたくなるか。
2. 綺麗にはまる形、引っ掛かる形、使いたくなる形はどれか。
3. ギリギリのバランスが成立する物理設定はどれか。
4. 3択と回転の有無で判断がどう変わるか。
5. 1×1から大きく育つ気持ちよさがあるか。接着は本当に必要か。
6. 消去・物理連鎖を入れるなら、積み上げの楽しさと両立するか。

プレイの感想には、設定、形、起きたこと、楽しい／不満な理由を記録する。次の機能は、その観察から選ぶ。
