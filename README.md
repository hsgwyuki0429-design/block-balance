# ブロックバランス

1×1の土台から、様々な凹凸のあるブロックを物理演算で積み上げるブラウザゲームの試作版。デザインや得点ルールよりも、形とバランスの手触りを試すための実装です。

## 起動

Node.js 22.12以上（24推奨）で、リポジトリ内から実行します。

```sh
npm ci
npm run dev
```

表示される `http://127.0.0.1:5173` を開きます。HTMLファイルの直接ダブルクリックではなく、開発サーバーで起動してください。

## 遊び方

1. 下の候補から形を選ぶ（1〜3キーでも選択可能）。
2. ゲーム画面上でマウス／タッチ、または左右キーで横位置を決める。
3. 「落とす」またはSpaceで落下。着地予測はありません。
4. 崩れても続行可能。「はじめから」で土台だけに戻ります。

土台は画面中央の下側に固定表示されます。カーソルは画面の左右端まで移動でき、左右キー／左右ボタンの長押しでも連続移動できます。カメラは構造物の広がりに合わせてズームし、カーソルだけでは動きません。落下や崩れの時間進行は従来の55％です。スマートフォンでは位置をタップした後に「落とす」を押します。

「試遊設定」で1択／3択、回転の可否、重力、摩擦を比較できます。回転を許可したときはRキー／回転ボタンで90度回転します。初期設定は3択・回転なしです。

## 実装範囲

Matter.jsによる複合剛体、10種類の形、固定1マス土台、落下中からの衝突・傾き・崩れ、自動カメラ、ロスト時の続行、休止とリセット。色は表示のみです。接着・消去・コンボ・確定スコア・ゲームオーバーは未実装です。

企画全体と未確定事項は [docs/DESIGN.md](docs/DESIGN.md) に記録しています。

## 開発・検証

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

ブラウザテストはインストール済みMicrosoft Edgeを使用します。Edgeのない環境ではPlaywright設定の `channel: 'msedge'` を除去し、`npx playwright install chromium` を実行してください。

- `src/shapes.js`: 形、色、候補の出現方式
- `src/physics.js`: 土台・複合剛体・構造の外形
- `src/main.js`: 入力、試遊設定、固定120Hz物理更新、描画とカメラ
- `tests/`: 土台への着地、凹みの衝突、転倒、形の連結、ブラウザ操作

本番用ファイルは `dist/` に生成され、サブディレクトリ配信にも対応します。自動公開・オンラインランキング・セーブ機能は含みません。大量に積む場合の性能や物理パラメーターは今後の試遊で調整します。
